## About LaraSvelte

LaraSvelte is a modern CMS platform built with Laravel, Inertia.js, and Svelte 5.

## Technology Stack

- **Backend**: Laravel 13 / PHP 8.3
- **Frontend**: Svelte 5 with Inertia.js
- **Styling**: Tailwind CSS v4
- **Database**: MySQL / PostgreSQL
